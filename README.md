# StreamVerse

A Netflix × anime styled directory of legal streaming sites. Static site for GitHub Pages.

- `links.json` — the list of categories and sites
- **Manage** button — add sites (with live embed preview), star as trusted, delete
- Changes save in your browser instantly; **Publish to site** commits `links.json` to this repo using a fine-grained token (Contents: read & write, this repo only) that stays in your browser.
